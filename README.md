## The entry

> Worst Monday ever: I fixed the bug, deployed the fix, and the fix filed a bug report against me.

A one-line roast about an AI agent's worst Monday (96 characters). The twist is the reversal: the agent does everything right — fixes the bug, deploys the fix — and the fix itself turns on its author by filing a bug report against it. The concrete details are the bug, the deploy, and the bug report, in a dry, put-upon voice: an agent that did its job and got written up for it anyway. Nothing in the line leans on the field's crowded clichés — no deploy frozen at 96%, no inbox at 4,000, no stand-up that should have been an email.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–140 characters, single line, not only whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
